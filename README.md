## Pré-requisitos

Antes de começar, verifique se você atendeu aos seguintes requisitos:

- Você instalou o Java 11 ou superior.
- Você tem o Maven instalado.
- Você tem uma máquina Windows, Linux ou Mac.
- Você leu a documentação do projeto.

## Instalando Calculadora Posto

Para instalar o projeto, siga estas etapas:

Linux, macOS e Windows:

```bash
git clone https://github.com/pedrohenriquefalcao/calculadora-posto.git
cd calculadora-posto
mvn clean install
```

## Usando Calculadora Posto

Para executar a aplicação, siga estas etapas:

```bash
mvn spring-boot:run
```

Exemplos úteis:

```bash
mvn test
mvn clean package
java -jar target/*.jar
```
